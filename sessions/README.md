# Sessions

Documented working sessions with Kiro (the AI development environment used on
this repo). Each file is a readable summary of one session: what was requested,
what was done, the decisions made, and the outcome.

These are historical records. The authoritative state of the project lives in
the specs (`.kiro/specs/`), steering (`.kiro/steering/`), and the code itself;
when a session note disagrees with those, the specs/steering/code win.
